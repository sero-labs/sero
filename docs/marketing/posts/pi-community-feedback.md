Your agents have outgrown the chat box.

If you use Pi, you already know the loop is the powerful part. What I kept
wanting was a real *place* for that loop to work — not just a prompt and a reply,
but browser state, terminal output, files, project memory, plugins, and
long-running workflows, all in one window.

So I've been building Sero: a local-first desktop workspace built on the Pi loop.
Same loop you know, with a product surface around it.

The part I'd most like Pi users to judge: Sero can build and run its own plugins.
I asked it for a release-checklist plugin — it wrote the plugin, I reviewed and
approved it, and it mounted as a panel inside Sero and produced a real
release-readiness report from the repo. Self-extending, with a human approval
step in the middle. [demo link]

It's early and it's beta, and it's very much the Pi loop underneath — this is
meant as a next step for that workflow, not a replacement for it.

The honest question: does a product surface like this feel like a useful
extension of the Pi loop, or too much surface on top of something that's already
good? And if it's useful — which part matters most to you: the visual browser,
durable loops, or self-built plugins?
