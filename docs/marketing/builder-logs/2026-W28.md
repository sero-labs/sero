# Sero Builder Log — 2026-W28

First builder log. These go out weekly: what shipped, what it means if you build
on Sero, and one thing we'd genuinely like your take on.

## What shipped this week

- **The Orchestrator** ([#224](https://github.com/sero-labs/sero/pull/224)) —
  durable, autonomous agent loops. A loop is a step plan Sero runs and recovers,
  not a one-shot prompt.
- **Reliability + docs** ([#225](https://github.com/sero-labs/sero/pull/225)) —
  Orchestrator fixes, and the docs split into a guide and a reference with
  screenshots.
- **Living loops + the Loop Catalog** ([#226](https://github.com/sero-labs/sero/pull/226)) —
  loops that react to events, pluggable delivery, and a catalog to install them
  from.
- **PR lifecycle loops** ([#227](https://github.com/sero-labs/sero/pull/227)) —
  loops that watch a pull request and keep it moving, on an isolated branch.

## What this unlocks if you build on Sero

Loops are now a first-class thing you can author, not just an internal feature.
So are plugins: we just re-checked the plugin developer guide by building a
working plugin from the published docs alone, and fixed every gap we hit — so a
first plugin shouldn't strand you on a wrong page.

Two good first projects:

- **A plugin** — a small app with its own UI and one tool. Start from the
  [Plugin Quickstart](https://docs.sero-ai.dev/reference/plugin-quickstart).
- **A loop** — a durable workflow that reacts to an event or runs on a schedule.
  Start from the Loop Catalog.
