Diff surface — prototype

Corrected model. There are two git surfaces and both contain their own diff: the full-screen Git app, and a simpler Source Control view inside the Explorer. Neither contains an editor. Opening a file switches you to the Explorer's Editor view and the git view goes away — they are modes that swap, not panes that share the screen.

1 · Explorer, Source Control view

Reached by the Source Control icon that already exists in the activity bar. Changes and history on the left, the diff filling the rest — the same two lists agreed in #301, at the same 300px, but the diff is in this view rather than in the editor. Sync and the branch live in the header; the real work stays in the Git app.

What this view is. #301's two lists, plus the diff they open. It is the cheap way to read what changed — no rail, no graph, no commit box, no PR. The header carries the branch, the sync counts and Fetch / Pull / Push so a glance-and-sync needs no other surface. Anything more than that is Open Git app.

↓ Click the file icon on a row — or the file name in the diff — and you leave for the Editor

2 · Explorer, Editor view — where files open

The Editor is its own view with its own icon. Opening a file from either git surface lands here and the git view is gone; clicking Source Control again brings it back exactly as it was. One mode at a time, in both directions.
