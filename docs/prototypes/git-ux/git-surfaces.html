Git surfaces — prototype

Two surfaces, drawn at real size with the real Sero dark tokens. The Git app owns the actual work; these two are the ways in and out of it. Nothing here is nested in a card, nothing has a badge, and no label explains another label.

1 · Explorer panel — at real width, beside a diff

300px, which is what you actually get. The point of the panel is that the list stays put while the diff changes — so the file rows are the only thing with any visual weight.

What was removed, and why

Hero sentence — "Wrap up the current changes and keep the branch moving." Told you nothing you couldn't see.

Stats strip — 22:58:06 · 0 staged · 1 changed · 0↑/0↓. Four facts, three of them repeated elsewhere in the same popover.

Two nested cards — Commit and Pull request were each a bordered box inside a bordered panel. Hairlines separate now.

The PR form — moved to the Git app. It never fitted in a popover, and it was byte-identical to the one in the sidebar.

"Ready" / "Live refresh active" — status labels for states with no action attached.
