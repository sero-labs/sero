Two rules I couldn't ask about in words

Both drawn at real size with the real tokens. Left-hand column of each row is what the prototypes already do; the alternatives sit beside it so the trade is visible rather than described.

1 · Row actions replace the line counts on hover

In every prototype, a file row shows +77 −14 at rest. Put the pointer on it and those numbers are swapped out for the action buttons — the row is the same width either way, nothing jumps. The cost: at the moment you reach for Discard, the size of the thing you're about to throw away has just disappeared. Second row down is shown hovered in all three.

1 and 3 keep amber. 2 and 4 go neutral. Modified files become grey dots, so added (green) and deleted (red) still read but "I touched this" stops shouting. Amber now appears perhaps twice a week instead of on every row — which is the point of a warning colour.

The catch: a grey dot beside a grey filename is nearly invisible, and modified is the status you scan for most. You'd be trading the loudest signal in the list for the rarest one.
