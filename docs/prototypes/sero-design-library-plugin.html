Design Library plugin — prototype

A private visual memory and creative workbench for Sero. Library captures design DNA, Design turns it into new work, and Gallery preserves the results. The imagery leads throughout; analysis appears exactly where it helps selection, generation, or reuse.

States 5A and 5B are two placements for the same Tweaks panel — the AI-authored CSS controls that belong to one specific generated page. Everything else is settled.

1 · Library — browsing and selecting inspiration

The default surface is a dense visual browser, not a metadata catalogue. Collections and smart groups stay in the left rail, lightweight filters sit above the work, and selecting references reveals one focused action bar.

5 · Tweaks — a fourth inspector tab in a resizable panel

The model authors controls for this specific page — display scale, metric density, signal accent — never a generic slider set. They live in the existing inspector, so no new chrome appears. The inspector is drag-resizable and its width persists, so the panel can be widened for a control-heavy design and narrowed again for the canvas.

8 · Settings — models, media and generation defaults

Analysis and generation are different jobs, so they get different models. Media is configured by capability, never by provider — the endpoint ids are editable text, the credential is read from the environment, and the spend limits are plain numbers. Everything here persists to plugin state.
