Pixel Studio

AI-authored sprite data, deterministic pixels. This prototype adds a Sprites surface to Design Library where text and visual references become validated palette-indexed matrices, editable animation frames and reproducible sprite-sheet exports.

The workbench below is interactive. Select frames, paint directly on the matrix, switch inspector tabs, play the animation, preview onion skinning, validate the document and open the project creation flow.
