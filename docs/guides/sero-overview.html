Sero

Zero context switch, zero sprawl.
An agent-first workspace for macOS — built on Pi, powered by containers.

1 — Vision & Philosophy

One beautiful, lightweight macOS desktop window. Every project is a workspace. Inside each workspace: a fully tiled, dynamic environment with everything the project needs — editor, terminals, previews, agent chats — no external apps.

Local-first execution using Apple's native Containerization framework. Agent-first: AI agents are woven into the workspace OS. The container is the body. The Electron UI is the face. Pi is the mind.

🧠
Pi is the Brain

Pi is not a plugin. It's the intelligence layer Sero is built on. Every decision the workspace makes flows through Pi.

📦
Container Sandboxing

Every workspace gets a dedicated Linux VM via Apple's Containerization framework. Agent tool execution is sandboxed inside containers.

🪟
Zero Context Switch

Editor, terminal, chat, previews — all in one window. No tab-switching between apps. Each workspace is self-contained.

6 — App System

7 — Container Integration

Every workspace gets a dedicated Linux VM via Apple's Containerization framework. The Pi SDK AgentSession runs on the Electron host; all tool execution is proxied into the container via container exec. Workspace files are bind-mounted.

If container fails to start, the session gracefully falls back to host-side tools. No hard crash.
8 — State Management

Zustand stores in the renderer, with IPC bridges to the main process. Persisted state uses a mix of localStorage, the workspace registry, and session .jsonl files.

10 — Sero Extension System

The Sero Extension (sero-extension.ts) is an inline Pi extension factory that provides cross-workspace intelligence. It hooks into the Pi SDK lifecycle to inject context and handle workspace-specific commands.

Extension Hooks

before_agent_start
Injects open workspace summaries into the system prompt. Adds container instructions if applicable.
input event
Expands @ws:id/path references to absolute filesystem paths before the agent processes them.
/workspace command
List, info, open, close workspaces from chat. Workspace management without leaving the agent.
JJ integration
Automatic JJ checkpoints after mutating tool calls. Checkpoint restore via jj restore.
