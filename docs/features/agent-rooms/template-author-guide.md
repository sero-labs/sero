# Author Room templates

Room templates are optional planning seeds. They guide the planner but do not
fix the final roster.

## Add a template

1. Copy one of the built-in presets in the Orchestrator Room templates module.
2. Give it a stable ID, a short title, and a plain-language purpose.
3. Add guidance for useful roles, work stages, and checks.
4. Do not add credentials, runtime state, fixed session IDs, or host paths.
5. Run the Room planner and template tests.
6. Test the template with at least two different problems.

The generated blueprint must still use one Conductor, available models and
capabilities, and the user's limits. A template must not grant authority. The
validated blueprint and operating envelope remain authoritative.

Use a template only when several problems benefit from the same broad approach.
Do not use one to recreate a fixed collaboration pipeline.
