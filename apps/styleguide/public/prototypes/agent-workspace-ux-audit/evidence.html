Agent and workspace UX audit — current state

Every frame below is the shipped Sero desktop build photographed against a copy of the seroarchitectdev profile: nine real Architect projects, the workflows of four workspaces, and every Room the profile holds. Nothing here is a mockup. The proposed designs live in a separate document so an attractive drawing is never mistaken for an observation.

The capture ran with the Architect, Rooms and Goals runtimes switched off (SERO_ARCHITECT=0, SERO_ROOMS=0, SERO_GOALS=0). No owner was woken, no model was called and no record was written, while the pages still render because they read their records from disk. Two consequences are on the frames and must not be read as product defects: a red "Room mode is not available for this workspace" banner, and a Run inspector that reports the Architect runtime is not running.

Nothing changed during the capture, so no frame shows a live transition. Every activity transition is listed as a gap at the end of this document rather than implied.
