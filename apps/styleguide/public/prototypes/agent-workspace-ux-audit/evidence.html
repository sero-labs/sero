Agent and workspace UX audit — current state

Every frame below is the shipped Sero desktop build photographed against a copy of the seroarchitectdev profile: nine real Architect projects, the workflows of four workspaces, and every Room the profile holds. Nothing here is a mockup. The proposed designs live in a separate document so an attractive drawing is never mistaken for an observation.

The Architect and Goals runtimes were switched off for the whole capture (SERO_ARCHITECT=0, SERO_GOALS=0): no owner was woken, no model was called and no record was written, while the pages still render because they read their records from disk. The Rooms walk is the one exception. A first pass with SERO_ROOMS=0 photographed every Room Activity feed, filter and Claims panel as empty, because those are served by the Rooms runtime rather than read from disk, so the Rooms here were re-captured with it on. Nothing ran: every Room is completed, cancelled or paused, the walk clicks no Resume, and the workspace records were byte-identical before and after, with recorded spend unchanged at $11.3360. One consequence of the first pass remains on the non-Room frames: a red "Room mode is not available for this workspace" banner, and a Run inspector that reports the Architect runtime is not running.

Frames are captured at 1440x920, inside the 1512x982 desktop. An earlier set was taken at 1600x1000, which the display silently clamped, so those frames were cut off at the right edge. Every frame here is measured for horizontal overflow at capture time and none is cut. The shell's workspace sidebar is collapsed except in the Workspaces section, where it is the subject.

Nothing changed during the capture, so no frame shows a live transition. Every activity transition is listed as a gap at the end of this document rather than implied.
