Goal mode — chat surface

A goal keeps one chat session working toward one objective until a completion contract is met. /goal starts it. This prototype answers two questions: where an active goal lives in the chat surface, and what an automatic continuation looks like in the transcript.

The user always wins

A queued message cancels the next continuation. Escape pauses the goal at once.

Silence is not a stop

The agent stops with a tool call: complete, blocked or waiting. Each one changes the banner.

A limit is not completion

Reaching a turn, token, cost or time budget reads as a stop, never as success.

Reported, not verified

Phase 1 shows the agent's claim. The word "verified" is not available yet.

A goal can take 25 automatic turns. Showing every one buries the work; hiding them all removes the audit trail. Compare the three options on the same three continuations. Use the buttons, or Tab to them and press Enter.
