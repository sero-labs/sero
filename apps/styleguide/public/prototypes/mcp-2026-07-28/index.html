Interactive prototype for issue 359. It is not the current product.

Review question

Do these screens show MCP apps, server input requests, tasks and remote skills clearly enough to build them? Do you accept the three default settings below?

Defaults to confirm

  • Remote skills are off until you turn each one on.
  • When no person can answer (a headless session or the plain Pi CLI), Sero declines a server input request at once.
  • A task result is added to its chat. It does not start a new agent turn.

Changes to current UI

  • A tool result can show UI from the plugin that owns the tool. The MCP plugin uses this for MCP apps.
  • The User Feedback questionnaire shows who asks the question.
  • MCP server details show the protocol, extensions, cache, transport and the failed step.
  • The MCP app gets Tasks and Remote skills panels.
  • The add-server form lists stdio and Streamable HTTP only. Saved SSE servers still connect.
