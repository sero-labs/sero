Memory lines in chat

The review question: how recall and saves show in the transcript after the memory rework. Recall is one line after your message. A change to memory is one line where the agent made it. A turn with no memory work shows nothing. The Memory toggle in the composer and the old "Memory (N sections)" card are removed.

One line eachRecall and each save, replace or remove use one line in the style of the goal-turn marker. No card.
Recall opens"Recalled N memories" opens to show each memory once: the fact, its behaviour and its id.
Other commands stay toolssero memory --help, list and failed commands keep the normal tool row, because the agent acts on their output.
Nothing when quietNo recall and no save means no memory line at all.
