Goal mode — Orchestrator and dashboard

Goals are the third Orchestrator mode. This prototype answers one question: how goals sit beside Workflows and Rooms without reading as workflows. A goal has no plan and no steps. It has an objective, criteria, a budget and a history.

Chat is the entry point

Goals start with /goal. This view manages the ones the user left running.

No plan, no steps

Nothing here shows a DAG, a step list or a retry count. That vocabulary belongs to Workflows.

A limit reads as a stop

An exhausted budget is shown in the error treatment, never as a finished goal.

One inbox

Blocked and waiting goals join the existing Needs You widget. No second queue.

1 · Orchestrator home — three modes, one list per mode

The Goals tab sits beside Workflows and Rooms. Selecting a row opens the detail in state 2. Try the tabs with the mouse or the keyboard.
