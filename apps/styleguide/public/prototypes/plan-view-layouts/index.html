Plan view — four denser layouts

A static comparison for the Orchestrator plan map. Every option shows the same plan: 15 steps in 12 stages, with one fan out, two approval gates, one branch, two parallel stages, and one loop back. Every option uses the same 1160 by 560 panel, the size of the plan map in the Workflow detail view.

The question to decide: which layout shows the most useful information for each step, and keeps a long plan readable, without a zoom control.

Decision

What to choose

A and B answer different questions. A is best when the user asks what happened, because the rows read like a log. B is best when the user asks what the plan does, because it keeps the map. C is the only option that keeps a 30-step plan on one screen. D gives the most text for each step, and it needs no drawing code.

  • Open question 1Do we keep the Map and Details tabs, or does one of these layouts replace both?
  • Open question 2Is the loop back common enough to need an arc, or is a label enough?
