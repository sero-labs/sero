Serpentine plan map — a tighter card, and a steps-per-row setting

A second pass on option B of the plan view layouts prototype. It keeps the same plan — 15 steps in 12 stages, with a fan out, two approval gates, a branch, two parallel stages, and one loop back — and the same 1160 by 560 panel.

Two changes: the card holds the same information in less space, and the user sets how many steps go in each row. The prototype is static. Each setting of the control is drawn on its own.

Card

What changed in the card

Same width (258 pixels), same information, 20 pixels less height. The state moves out of the header into the one meta line, so the header carries only the number and the title.

  • The title is the first line. The stage number moves to the right corner, where it does not compete with the title.
  • The state word and its dot were on two elements in the header. Now one state chip sits with the agent, the marks, and the time on one meta line.
  • The time was pushed to the far right of the meta line by the space between. Now it sits at the end of the same line, and it aligns down the column.
  • A colour bar on the left edge carries the state, so a scan down a column reads the states before it reads the words.
  • The old card kept 25 pixels of empty space below the outcome, because one node size had to hold a two-line title and a two-line outcome. The outcome is now one line, and it ends with an ellipsis when it is longer.

Decision

What to decide

  • Default4 per row fits the most plans without a scroll. 3 per row reads better because titles stop wrapping. Which is the default?
  • Where the setting livesThe control replaces the Auto, Horizontal, and Vertical buttons. It must persist in the layout file, like the other view settings.
  • The labelA column holds one stage. A parallel stage puts two steps in one column, so "steps per row" is not exact. "Stages per row" is exact, but the user counts steps.
  • Wrap and loop marksThe wrap line is dashed and labelled. The loop rail is violet. Is a label needed at each wrap, or only at the first?
