Start with [Plugin Quickstart](/reference/plugin-quickstart) if you are a new
author. It gives you one complete journey from the maintained Notes example to
an active local development session.

Use an extension-only plugin when you need only Pi tools or commands. Add a UI
when a user must interact with the plugin directly. Add a background runtime
only for long-running work, such as watchers, recovery, or orchestration.
