# Orchestrator

Orchestrator helps Sero manage work that needs more than one agent turn. Open
it from the app bar, then choose **Workflows** or **Rooms**.

## Choose the right mode

| Choose | When the work needs | Example |
| --- | --- | --- |
| [Workflow](/guide/workflows) | a planned set of steps that can run once, on a schedule, or after an event | Check a repository each morning and prepare a report |
| [Room](/guide/rooms) | several agents that share findings and change the plan while they work | Find the cause of a security problem, fix it, and review the fix |

A Workflow follows a step plan. A Room forms a temporary team. They are
separate ways to run work. You do not need to create a Workflow before you
start a Room.

## What you control

Orchestrator shows you the proposed work before it starts. You can review where
the agents work, what they can access, where results go, and the limits that
apply.

Work can stop when it needs:

- an answer from you;
- approval for an external action;
- more time, cost, access, or team members;
- help after a failed or blocked task.

You can close the Orchestrator panel while work continues. Open **Home** to see
items that need your attention.
